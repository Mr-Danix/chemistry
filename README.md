# Chemistry Website

A simple educational chemistry website that helps students understand basic chemistry concepts through a clean and easy-to-use interface. The site presents important topics, explanations, and learning materials in an organized way to support beginner learners.

---

## 🌍 Live Demo                                              

🔗 https://mr-danix.github.io/chemistry/

---

## 🚀 Features

- Simple explanations of basic chemistry topics
- Clean and easy navigation
- Organized sections for learning
- Responsive design for different devices
- Beginner-friendly layout

---

## 🛠 Tech Stack

- HTML – Page structure and content  
- CSS – Styling and layout design  
- JavaScript – Basic interactivity
